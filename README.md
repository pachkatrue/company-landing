# Company Website

Responsive company landing page built with Next.js and TypeScript, with a focus on performance, accessibility, SEO and responsive UI.

## Preview

[Live demo](https://company-landing-site.netlify.app)

![Project preview](https://d33wubrfki0l68.cloudfront.net/6ab27d73225ab00008ff4af7/screenshot_2026-09-22-13-07-56-0000.webp)

## Highlights

- Responsive layout for desktop and mobile
- Contact form with validation
- API endpoint for form submission
- SEO metadata and Open Graph / Twitter cards
- Semantic HTML and keyboard-friendly interactions
- Optimized YouTube embed
- Performance-focused rendering and loading strategies

## Tech stack

- Next.js 15.5
- TypeScript
- Material UI
- Styled Components + Emotion
- Intersection Observer API

## Getting started

Requirements: Node.js and npm (or Yarn).

```bash
npm install
npm run dev
```

Open the local development server in your browser.

Production build:

```bash
npm run build
npm run start
```

## Project focus

This project demonstrates frontend implementation with attention to responsive design, accessibility, SEO and performance rather than only visual layout.

## Code quality

ESLint is configured through Next.js' flat-config-compatible setup and can be run with:

```bash
npm run lint
```

## Deployment

The project can be deployed through a Git-based CI/CD provider such as Netlify or Vercel. Build configuration should match the deployment adapter and framework version used by the project.
